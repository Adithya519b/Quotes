# Random Quote Generator
A simple and responsive web app that fetches random quotes from a public API and displays them on the screen. 
Users can click a button to load a new quote.
# Features
Fetches live data dynamically from a public API.
Click a button to generate a new random quote.
Clean and simple user interface.
Fully mobile-responsive layout.

HTML5 
CSS3
JavaScript (ES6)
